# Codebase for ENG1 Project
Private repository for the ENG1 codebase.
# How to run this game

From the 'ENG1' folder:

Windows: gradlew.bat lwjgl3:run
Linux: ./gradlew lwjgl3:run


## Credits

Parts of the game loop, `GameObject`, `Player`, `Goose` and `Interaction` are
adapted from Quillraven's libGDX "Slime Survivor" tutorial, which the team used
as a starting point.
